# 企业家演示脚本

建议先让用户自行观看首页，再点击“看一次完整闭环”。不承诺演示中的线索和回复来自真实运行。

1. **现有产品**：已有棉麻与全棉资料。系统在经营范围内持续研究，无需反复下任务。
2. **客户背调**：Seabrook 的业务、采购角色、历史关系和未知项都有位置。
3. **开发材料**：基于已确认产品生成介绍，模拟发送，不承诺未知条件。
4. **明确需求**：客户回复确认直接采购并索要产品资料，销售接受交接。
5. **关键变化**：Lund 只接受纯麻，原混纺材料失效，其他客户不受影响。
6. **产品机会**：第二个独立项目出现相同要求，汇总证据但不虚构市场规模。
7. **知识确认**：产品负责人确认现有纯麻产品资料后，企业能力才更新。
8. **重新匹配**：受阻机会获得替代产品依据，循环回到下一轮开发。

演示后询问：哪一步现在最耗时？现有 CRM 能做到多少？推荐是否值得业务员使用？能否拿一组脱敏资料做比较？不要只问“你觉得 AI 厉不厉害”。

可单独展示数据连接页面，解释 ERP 和 CRM 的原有角色。所有页面标注演示数据，邮件和回写按钮明确为模拟。
