# ADR 0003：订单确认与老板价值演示

日期：2026-09-18；状态：已按用户要求进入交互演示实现。Issue：#3。

## 背景

售前 v0.2 已展示机会、回款背调和产品接入。用户进一步讨论售中售后，并要求根据商业产品及开源调研提供推荐 PRD，随后确认继续做 Demo 及直观价值演示。

## 决定

保留 v0.2 售前业务。新增独立订单确认状态及轻量客诉证据页，用一笔虚构订单展示跨资料差异、角色确认、导出和变更影响。采用独立 `boss.html` 解释业务问题与产品价值，沿用同一 GitHub Pages 发布。

订单事件由纯函数维护；内部批准、客户接受、ERP 回执按版本分开记录。数量变化不抹去已确认的幅宽、单位与样品范围，但会使相关价格/交期判断、审批和待发草稿待复核。旧确认包不可静默覆盖。

老板演示可自动播放与手动操作，提供假设价值测算。时间释放是产能价值，不等于节省现金；不声称实测转化或收入提升。

## 取舍与边界

本次实现覆盖 PRD 中的交互演示，不宣称实现生产解析、多人权限、实时 AI、真实邮箱或 ERP 写回。订单与售前状态分存，以保留已有演示进度。原始资料为内置虚构片段，客诉属于独立未来场景示例。

## 被替代的范围

此前“当前仅聚焦售前”的阶段范围扩展为“售前加订单确认与客诉证据交互”。全供应链托管与自主商业承诺仍不进入本版。ADR 0001、0002 的来源与未知项原则继续适用。
