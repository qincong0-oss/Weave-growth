# 企业产品接入：Demo 与 P1 接口约定

此文是本项目拟定的对接契约，不是金蝶、用友或其他厂商已实现的接口文档。

## 当前能操作的内容

| 来源 | Demo 行为 | 真实接入前提 |
| --- | --- | --- |
| 现有 ERP / 产品 API | 读取预设响应样本；选择系统名称、映射和复核 | 企业授权、对应版本接口文档、服务端适配与权限 |
| Excel / CSV | 实际本地读取 UTF-8 CSV，支持 BOM、引号逗号和换行；最多 100 行 / 256 KB | Excel 另存 CSV；原生 XLSX 解析未实现 |
| 规格单 / 产品册 | 展示预设提取样例，未知起订条件保持未知 | 文件上传、OCR、多模态提取、原文定位与授权存储 |

## 产品字段

料号、名称、成分比例、克重和幅宽为本 Demo 必填。成分比例合计 100%；克重支持 g/㎡、gsm，幅宽支持 cm / m；非正数、未知单位或缺失字段会阻止该行入库。起订条件、用途与补充条件可缺失；新产品缺失值保持未知，已有产品未提供的可选字段保留原值。

料号只允许文字、数字、点、短横线和下划线。正式主键为 tenant_id + source_system + material_id（及颜色/规格 variant_id）；本单企业 Demo 按企业料号关联。同一源列不能同时映射到多个目标字段，批次重复料号被标记。确认前不用于对外介绍。

## P1 服务端同步流程

企业管理员授权只读账号 → 列举产品变更 → 写入原始记录 → 单位/字段标准化 → 确定字段权威来源 → 校验与差异队列 → 资料负责人确认 → 发布产品版本 → 失效相关材料并重算受影响判断。

建议响应结构：

```json
{
  "source_system": "customer-erp",
  "cursor": "opaque-next-cursor",
  "items": [{
    "material_id": "HX-L240",
    "source_version": "v3",
    "updated_at": "2026-09-17T08:00:00Z",
    "name": "自然肌理棉麻",
    "composition": [{"fiber": "linen", "percent": 55}, {"fiber": "cotton", "percent": 45}],
    "weight": {"value": 240, "unit": "g/m2"},
    "width": {"value": 145, "unit": "cm"},
    "moq": {"quantity": 300, "unit": "m", "scope": "natural colour only"}
  }]
}
```

游标仅在批次持久化成功后推进。幂等键用租户、来源、料号与源版本组合；失败重试不重复建档。取消/停用是显式状态，不能因本次增量未出现而推断产品删除。接口凭证只保存在后端密钥存储中，前端和公开 Git 均不保存。

## 与回款背调的数据关系

产品 API 不等于财务接口。回款数据需单独授权客户主档、发票、到期日、到账核销、贷项/退货/争议及币种；登记主体和 ERP 客户要先匹配。部分付款按未结清余额计入应收；不同币种分别计算。财务审批、信用报告、保险额度与付款主体由独立数据源维护，不从销售回复中生成。
