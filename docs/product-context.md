# 产品共识

## 目标

面向柯桥面料企业，通过现有产品驱动持续客户开发，帮助企业获得有依据的售前结果，并把员工和 AI 的工作成果积累为公司知识。

当前 Demo 的商业目标是让纺织企业家看见值得试用的业务改善，并获得可以检验的反馈。演示兴趣不等于付费意愿，生成线索不等于收入。

## 用户已经确定的方向

1. 聚焦售前。售中与售后、完整供应链托管暂不展开。
2. 产品和经营资料接入后持续运行，取消每轮人工创建开发任务。
3. 客户背调是核心能力，对标 OKKI AiReach。
4. 同时发现现有产品销售机会、相邻应用机会与产品改进空间。
5. 反馈循环形成有来源、有范围的标准企业知识与上下文。
6. 企业已有 ERP、CRM 时保留其职责，证明增量价值。
7. GitHub 保存代码与项目共识，支持多位成员使用不同 AI 协作。
8. `@0xrelander` 为项目协调人，Nick 为产品与商业负责人。

## 曾讨论但已被替代的方向

“先创建开发任务再启动 AI”已由持续运行方案替代。全链条托管开发、自动报价和采购执行不作为首版卖点。不能再把通用 CRM 描述为仅能存储数据，也不能假定通用 AI 产品没有企业知识能力。

## 核心验证问题

匹配建议是否优于企业现有做法？背调的来源和采购角色是否准确？业务员是否接受交接？减少的工作时间是否超过审核与维护成本？产品机会能否得到独立需求支持？交付是否可以重复、能否支撑续费？

## 信息标准

企业确认事实、客户明确表达、公开观察与 AI 推断分开记录。知识至少带来源、时间、适用范围、负责人和确认状态。客户沉默不能解释为需求不存在；个别反馈不能直接推导市场趋势。
