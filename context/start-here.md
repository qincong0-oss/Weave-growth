# 新成员与新 AI 会话入口

在这个仓库中开始新会话时，可以使用以下指令。产品共识以仓库中的最新版本为准，不依赖某个模型记住旧聊天。

> 请先阅读 AGENTS.md、context/current-state.md 和 docs/product-context.md，再根据本次任务读取相关 PRD 与决策。说明本次要解决的业务问题和影响范围，然后完成实现与必要验证。不要把演示能力当作真实连接，不要未经依据扩大售前范围。完成后更新当前状态；涉及长期决定时追加决策记录，并在 PR 中说明实际验证结果。

本次任务应另附 Issue 编号、预期结果和验收条件。协调人维护工作之间的依赖，产品负责人确认优先级与商业边界。
